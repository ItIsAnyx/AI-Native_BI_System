# Сценарии, технические критерии и результаты

## Сценарии


| № | Сценарий | Наш результат |
|---|---|---|
| 1 | Обзор неизвестного набора | Реализовано: столбцы, типы, статистика, количество строк и диапазон дат. |
| 2 | Значения полей и связи ID | Реализовано: частоты, группировки, соединения и вычисления. Шесть контрольных расчётов прошли через реальную модель. |
| 3 | Сводки, повторы и выбросы | Реализованы календарные группировки, поиск дубликатов и базовых аномалий. Полная приёмка свободных формулировок не завершена. |
| 4 | Наглядное представление ответа | Семь типов графиков, выбор параметров моделью |
| 5 | Панель показателей | Дашборд из 2–6 панелей, сохранение и повторное получение из истории и Dashboard. |
| 6 | Продолжение предыдущего анализа | Серверная история, источники и сокращение контекста. Длинный многошаговый диалог требует отдельной приёмки на модели. |
| 7 | Временные повторения — дополнительный | Базовый анализ сезонности; требуется минимум три полных цикла. |
| 8 | Сегменты по нескольким признакам — дополнительный | Группировки по комбинациям полей и сравнение агрегатов; полная проверка на модели не завершена. |
| 9 | Связи с временным сдвигом — дополнительный | Реализованы лаговые корреляции. Причинные выводы не реализованы. |
| 10 | Будущие значения и сценарии — дополнительный | Базовый линейный прогноз и наблюдаемая регрессия «что если»; это оценки, не гарантии и не причинная модель. |

## Технические критерии

| № | Требование | Наш результат |
|---|---|---|
| 1 | Чтение непосредственно из БД | Поддержан PostgreSQL: настроенные подключения, выбор таблицы, read-only чтение. Живой аналитический источник ещё не проверяли. |
| 2 | Приём исходных CSV и обработка внутри | Реализовано. Поддержаны `;`, десятичная запятая, ID и возвраты; преобразования создают отдельные результаты. Есть лимиты объёма и памяти. |
| 3 | Понятное исследование и ответы | Есть профиль данных и расчётные инструменты. Все шесть контрольных вопросов сверены на полных файлах через локальную модель. |
| 4 | Графики из диалога и смена представления | Инструменты доступны агенту; параметры и тип графика выбираются по запросу. Сквозная браузерная приёмка всех вариантов не завершена. |
| 5 | Сохранение созданной панели | PNG и параметры сохраняются, доступны из чата и библиотеки Dashboard. Повторное получение проверяется автотестами. |
| 6 | Результат для бизнес-пользователя | Таблицы, русские подписи и пояснения формул; выводятся фактически рассчитанные числа. Итоговая ручная оценка UX ещё нужна. |
| 7 | Сохранение контекста беседы | История хранится по чатам; источники и результаты переиспользуются, длинный контекст сокращается. |
| 8 | Обработка ошибочных запросов | Проверяются столбцы, периоды, статусы и параметры; есть исправление вызовов, уточнения, отказы и отмена обработки. |
| 9 | Локальное развёртывание | Backend, frontend и модель работают локально. Конфигурация Compose проверена; чистый запуск всего решения через Docker ещё не принят. |
| 10 | Локальный открытый стек | Облачные API не используются в текущей конфигурации; модель исполняется в Ollama. Полная проверка лицензий зависимостей не проводилась. |
| 11 | Ограниченные сетевые обращения без поиска | Поисковые движки не подключены; используются настроенные адреса Ollama и БД. Отдельная принудительная сетевая allowlist не реализована. |
