# Локальный чат

Приложение использует локальную чат-модель через `transformers.pipeline`.
Модель загружается один раз при запуске. Отдельный сервер модели не нужен.

Из папки `backend` скопируйте `.env.example` в `.env`, укажите `BACKEND_KEY`,
`MODEL_PATH`, затем запустите:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Swagger UI: `http://127.0.0.1:8000/docs`.

Пока моделей нет, оставьте `MODEL_PATH` пустым: приложение запустится, а запрос
к модели вернёт `503`. Для подключения положите модель с конфигурацией,
токенизатором и шаблоном чата в `backend/models` и укажите, например,
`MODEL_PATH=models/my-chat-model`. Относительный путь считается от `backend`.
После изменения пути перезапустите приложение. Веса автоматически не скачиваются
и не добавляются в Git. Модель должна поддерживать `text-generation` в Transformers.
`MAX_NEW_TOKENS` ограничивает длину генерации, в том числе при пересказе;
отдельной проверки или ошибки по длине пересказа нет.

`POST /agent/response` принимает заголовок `BACKEND_KEY`, поле формы `payload`
с JSON и необязательное поле `file` с CSV:

```json
{
  "message": "Что есть в этих данных?",
  "context": []
}
```

Если контекст пуст, системный промпт добавляется автоматически. Если backend
передаёт системный промпт, он должен быть первым сообщением контекста.
Новое сообщение передаётся только в `message`, повторять его в `context` не нужно.

CSV читается в `tools/dataset.py`: pandas определяет разделитель, названия колонок
и строковые значения очищаются от пробелов. Поддерживается UTF-8 с BOM и без него.
Модели передаются число строк, статистика колонок и пять примеров записей.
Информация о файле добавляется к первому системному сообщению и сохраняется
при пересказе. Оригинальный файл приложение не хранит.

Если сумма символов в контексте превышает `MAX_CONTEXT_LENGTH`, все сообщения,
кроме первого системного и последнего пользовательского, пересказываются одним
запросом к модели. Они заменяются одним сообщением с пересказом. Предыдущий
пересказ также входит в следующий пересказ. Отдельного лимита длины пересказа нет.
Если пересказывать нечего, контекст отправляется модели без изменений.

Ответ содержит `message` и `context`. `context` — обработанный контекст с добавленным
ответом модели, а не полная история чата. Backend сохраняет полную историю отдельно,
а возвращённый контекст использует для следующего запроса.

Лимит в символах только запускает пересказ и не гарантирует попадания в окно модели.
Большой файл, длинный последний запрос или слишком поздний пересказ могут превысить
это окно; на данном этапе автоматического разбиения на пакеты нет.
